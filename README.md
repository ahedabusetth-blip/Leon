# Leon Template 🌐

قالب تصميم ويب عصري ومتجاوب (Responsive Web Template) مصمم باستخدام HTML و CSS لتقديم واجهات مستخدم احترافية.

---

## 🚀 نظرة عامة على المشروع
تم بناء هذا المشروع ليكون قالب موقع تعريفي (Landing Page) متكامل يناسب الشركات والمصممين والمطورين لعرض أعمالهم وخدماتهم بشكل جذاب.

---

## ✨ المميزات الرئيسية (Features)
* **تصميم مرن ومتجاوب:** يتوافق مع مختلف أحجام الشاشات والأجهزة.
* **قسم الخدمات (Services):** يعرض الخدمات المختلفة (Graphic Design, UI/UX, Web Design, Web Development) مع أيقونات معبرة.
* **معرض الأعمال (Portfolio):** قسم مخصص لعرض المشاريع السابقة مع تفاصيل لكل مشروع.
* **قسم حول الموقع (About):** نبذة تعريفية مع تنسيقات بصرية مميزة.
* **تواصل معنا (Contact):** روابط مباشرة للتواصل وأيقونات منصات التواصل الاجتماعي.

---

## 🛠️ التقنيات المستخدمة
* **HTML5**[cite: 1] - لهيكل وبناء صفحات الويب.
* **CSS3** - لتصميم وتنسيق الواجهات والألوان.
* **Font Awesome** - لتوفير الأيقونات الحديثة.
* **Google Fonts** - لتحسين الخطوط ونوعية العرض (خطوط Tuffy و Work Sans).
